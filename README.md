# Elf-speech

Software for vintage speech synthesizer chips on a CDP1802 Elf, written for
the [ElfC](https://github.com/arhefner/ELFC) C compiler so that the same
programs run under both Elf/OS and ELF-DOS.

| Folder | Synthesizer | |
|--------|-------------|-|
| [SP0256-AL2](SP0256-AL2) | General Instrument SP0256-AL2 | `say`, `saytime` and `speak`, and the `say` library. |
| DigiTalker | National Semiconductor DigiTalker | To come, when the hardware is built. |
| Votrax | Votrax | To come, when the hardware is built. |
