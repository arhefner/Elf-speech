# Elf-speech

Software for vintage speech synthesizer chips on a CDP1802 Elf, written for
the [ElfC](https://github.com/arhefner/ELFC) C compiler so that the same
programs run under both Elf/OS and ELF-DOS.

| Folder | Synthesizer | |
|--------|-------------|-|
| [SP0256-AL2](SP0256-AL2) | General Instrument SP0256-AL2 | `say`, `saytime`, `speak`, `calculate` and `sayface`, and the `say` and `face` libraries. |
| [CTS256A-AL2](CTS256A-AL2) | General Instrument CTS256A-AL2 with the SP0256-AL2 | `cts256` and `cts256face`, text to speech as the CTS256A-AL2 does it, the second with a talking face, and the `cts` library. |
| DigiTalker | National Semiconductor DigiTalker | To come, when the hardware is built. |
| Votrax | Votrax | To come, when the hardware is built. |
